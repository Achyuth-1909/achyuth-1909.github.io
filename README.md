## Before publishing
Replace these placeholders in `index.html`:
- `[Start Month Year] – [End Month Year / Present]`
- `[Location / Remote]`
- `[your.email@example.com]`
- `[+91 XXXXXXXXXX]`
- `[Add LinkedIn URL]`
- `[City, Country]`
- `[Full-time / Freelance / Contract]`

Do not publish confidential Talent Origins client names, candidate data, internal databases, pricing, or unreleased business information.

## Free public hosting options

### GitHub Pages
1. Create a GitHub account and a new public repository, e.g. `achyuth-portfolio`.
2. Upload `index.html` to the repository root.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. Your site will usually be available at:  
   `https://YOUR-GITHUB-USERNAME.github.io/achyuth-portfolio/`

### Netlify Drop
1. Go to https://app.netlify.com/drop.
2. Drag the `portfolio` folder containing `index.html` onto the page.
3. Netlify publishes a live URL immediately.
4. Create a free account to keep the site and rename the URL.

### Vercel
1. Create a Vercel account.
2. Choose **Add New → Project** and import the GitHub repository.
3. Accept the default settings and deploy.
4. Vercel provides a public URL such as `https://your-project.vercel.app`.

## Recommended final URL
Use a simple URL such as:
- `achyuthkumar.netlify.app`
- `gregjones-research.github.io`
- `achyuth-portfolio.vercel.app`

Add the final live URL to your resume, LinkedIn headline/about section, and email signature.
